with Minecraft becoming an increasingly resource-demanding game, certain features restricting gameplay, and many mods simply being fun to play with, knowing how to mod your game is getting increasingly useful. learning how to do so can be a bit intimidating, however, especially if you're not that tech-savvy, so here's a little guide!

> [!info]
> i'm only going to be talking about **Minecraft: Java Edition**, here, not Bedrock Edition. Bedrock is a lot more complicated as it's cross-platform, and not my area of expertise. as far as i know, modding it in the same way you can Java isn't possible. sorry!

# getting a launcher

the launcher is the program you open that lets you log in, choose your version, and start Minecraft. chances are that you're using the official launcher, which looks like this:

![the default view of the _Minecraft: Java Edition_ tab on the Minecraft Launcher](https://minecraft.wiki/images/Launcher_JE_tab.png?7ea07)

it's a pretty nice launcher, but it makes it a bit difficult to mod the game. if you want to switch between different groups of mods, you have to manually choose which ones in your file explorer every time, and it gets annoying, especially if you have different servers or worlds you play on that require different mods.

for that reason, people have made third-party launchers which make modding the game a lot easier. these launchers separate all of the files for each "profile" or "instance" you make. all of your settings, screenshots, worlds, and servers are separate for each one, as well as your mods, too!

the most popular ones are [Prism Launcher](https://prismlauncher.org/), the [Modrinth App](https://modrinth.com/app), and the [CurseForge App](https://www.curseforge.com/download/app). Modrinth and CurseForge are both sites that host downloads for Minecraft mods and similar, with their apps offering integration with their libraries, while Prism is just a launcher, and offers integration with both Modrinth *and* CurseForge.

because Prism is the more flexible of the three, it's what we'll be going with in this guide. you can download it for any computer operating system [here](https://prismlauncher.org/download). go do that and install it.
